# 07 전환 재생과 이전 실행 무효화

콘텐츠가 전환 시작과 새 구역 준비 완료를 요청하면 엔진이 페이드·2D 시간·완료 통지를 제공한다. 어느 배로 이동할지, HP를 어떻게 유지할지, 사망/승리 중 무엇을 선택할지는 이 서비스가 결정하지 않는다.

## 읽는 순서

1. `src/Presentation/Transition.h/.cpp`: Begin → FadeOut → Playing → WaitingForScene → SceneReady → FadeIn → Complete. Skip은 자연 종료와 같은 WaitingForScene으로 간다.
2. Token과 TakeNotices: 이전 전환의 늦은 완료를 거부하고 상태 진입 통지는 한 번만 꺼낸다. Reset/새 Begin은 새 token을 사용한다.
3. `src/Core/Events.h`: 소유 객체가 살아 있는 구독자에게만 전달한다. Reset은 epoch를 바꾸고 대기 이벤트·구독을 제거한다. 이전 epoch의 새 발행도 거부한다. 이벤트 처리 중 생성한 이벤트는 다음 Dispatch에서 전달한다.
4. `src/Editor/Editor.cpp`: 엔진 서비스의 사용 예제. 전투 시계는 멈추고 연출 시계로 Advance한다. 예제에 필요한 준비 완료/실패 버튼은 실제 구역 로더를 대신하는 명시적인 시험 장치다.

## 2D 자료 형식과 표시

이번 구현 선택은 version 1 JSON의 레이어와 WIC가 읽을 수 있는 이미지다. 레이어에는 화면 비율 좌표의 시작/끝 위치, 크기, 확대 배율, 색과 선택적 texture 경로가 있다. texture는 JSON 파일 기준 상대 경로다. 이동/확대는 선형 보간이며 예제는 직접 만든 색상 도형이다. 실제 탈출 일러스트·영상·프레임 시퀀스 제작 완료를 의미하지 않는다.

`data/presentation/preview.json`을 참고한다. `TextureCache`는 파일을 RGBA로 해석하고 DX11 텍스처를 재사용한다. UI용 Unorm·단일 mip이며 재질/PBR용 색 공간·밉 처리와 구분한다. 에디터 미리보기는 레이어 리소스를 미리 확인한 뒤 시작한다. 누락은 오류이며 준비 완료로 치환하지 않는다.

## 실행

에디터의 Transition preview를 펼쳐 Start preview → Skip 또는 자연 종료 → Scene ready를 실행한다. 준비 완료 전에는 암전에서 대기하고 전투 시계는 멈춘다. Simulate failure는 실패를 표시하며 Reset preview로 정리한다. 편집기 조작 창은 시험을 위해 암전 위에 남겨 둔다. 최종 게임용 화면 구성은 렌더·콘텐츠가 연결한다.

로드/재시작 시 사용할 정리 순서는 콘텐츠 입력·공격 중단 → 이벤트 Reset → 판정 Reset → 전환 Reset → Scene 교체 → 새 구독/상태 구성이다. 공유 모델은 마지막 참조가 사라질 때만 해제한다. 전환 완료만으로 게임을 재개하지 말고 콘텐츠의 새 구역 준비 조건도 확인한다.

## 검증 결과

2026-10-06 Debug/Release 빌드·엔진 테스트·삼각형/장면/에디터/2D 미리보기 smoke-test 통과. 스킵 중복, 준비 이전의 재개 방지, 잘못된 token, 준비 실패, 자연 종료와 스킵의 같은 경로, 재시작 이후 늦은 이벤트, 삭제된 구독자, 콜백 중 Reset을 확인했다. 페이드 경계 비교 오류를 발견해 수정하고 재검증했다.

2D GPU 캡처에서 레이어 이동 표시와 전투/탈출 시계 정지를 확인했다. 검 FBX의 GPU 프로브에서 생성한 이미지로 WIC 디코딩·업로드·텍스처 캐시도 확인했다. 세 구역 완주·실제 실패 HUD·소리·사망 우선 규칙은 콘텐츠 통합 후 검증할 항목이다.
