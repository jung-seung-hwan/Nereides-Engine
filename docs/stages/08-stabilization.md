# 08 기반 안정화와 통합 인계

2026-10-06 공통 기반을 연결한 뒤 경계 동작과 독립 실행을 점검했다. 최종 게임·최종 렌더의 합격 단계와 구분한다.

## 정리한 구현

- 객체 생성 순서에 의존하지 않도록 전역 Logic → Animation → Late 갱신을 명시했다. 프레임 중 생성·부착은 다음 프레임부터 갱신한다.
- 창 밖의 마우스 해제와 캡처 상실, 최소화 시 입력 잔존을 정리했다. 정지/편집 중 변환 변경을 전투 충돌 후보로 처리하지 않는다.
- 클립 길이보다 긴 블렌딩도 최종 포즈까지 도달하도록 수정했다. 지원하지 않는 FBX shear 변환을 조용히 잘못 변환하지 않고 오류로 반환한다.
- 잘못된 저장값이 기존 정상 파일을 교체하지 않도록 검사를 보강했다. 로드 후 월드 행렬 overflow와 카메라 유효성을 검사한다.
- 초기화/렌더 실패 경로에서도 에디터 콜백을 먼저 해제한다. 실행 경로가 bin 또는 배포 폴더여도 프로젝트/data 기준을 찾는다.
- .clang-format으로 코드 배치를 통일하고 현재 API와 수명 계약을 별도 [연결 안내](../integration-contracts.md)에 기록했다.

Debug/Release x64 빌드와 아래 검사가 통과했다. 테스트 구현은 `src/Tests/EngineTests.cpp`, 반복 실행 명령은 `scripts/verify.ps1`에서 확인한다.

에디터와 2D 미리보기의 GPU 캡처를 직접 확인했다. 실제 키보드/마우스의 모든 조합, 다중 모니터/DPI, GPU Live Object 보고 전체 판독, 다른 PC의 런타임 설치 상태까지 검증한 것은 아니다.

## 초기 측정

로컬 DX11 장치는 NVIDIA GeForce RTX 3060으로 확인했다. Release 임시 도형 장면, 1280×720, 편집기 비표시, VSync 켬, 30프레임 예열 후 180프레임의 한 측정에서 평균 16.68ms, 95백분위 16.91ms, 프로세스 working set 약 51.1MiB였다.

이 값은 Present 대기를 포함한 프레임 경과 시간이다. GPU 단독 시간이나 FHD 전투 성능, 효과가 겹친 장면의 60FPS 달성을 증명하지 않는다. `--benchmark`로 같은 조건을 다시 측정할 수 있다. 최종 성능 평가는 렌더·실제 콘텐츠 통합 후 별도로 수행한다.

## 배포와 다음 작업

`scripts/package.ps1`은 매번 새 dist 하위 폴더를 만들고 기존 산출물을 덮어쓰지 않는다. 설치된 라이브러리의 DLL과 copyright, data, 안내 문서를 포함한다. 외부 assets는 자동 포함하지 않는다. 개발 PC에서 별도 폴더 실행을 확인했으며 새 PC의 MSVC 런타임 설치는 배포 검증에 남는다.

이제 팀원이 공통 API를 사용해 실제 플레이어/보스 전투를 연결할 수 있는 상태다. 광원·환경·최종 재질 입력 확장과 Sherlock 포팅, 별도 모션 연결·에셋 외형 대조, 실제 첫 전투 사이클·HUD, 세 구역 준비/승패/재시작·오디오를 통합해야 한다. 원문의 미정 게임 수치는 이 구현으로 확정하지 않았다.
