# 05 충돌 후보와 진입 시각

엔진은 충돌 사실을 모으고 콘텐츠가 결과를 판단한다. CollisionWorld는 HP·패링·Stagger를 변경하지 않는다.

## 읽는 순서

1. `src/Collision/Collision.h`: Collider → CollisionShape → Contact → CollisionWorld. Collider는 객체에 붙이고 매 프레임 월드 형태로 수집한다.
2. `Collision.cpp`의 Collect: 실제 디버그 표시와 판정이 공유할 구·월드 AABB를 만든다.
3. Sweep/Step: 이전·현재 위치 사이의 선형 이동에서 최초 접촉 비율을 계산하고 후보를 모은다. 구끼리, AABB끼리, 구와 AABB를 지원한다.
4. Raycast: 가장 가까운 대상과 거리를 반환한다. HitLedger는 콘텐츠가 유효한 결과를 수락한 뒤 공격/대상 중복을 기록할 때 사용한다.
5. `Tests/EngineTests.cpp`의 TestCollision: 빠른 이동·탈출 시각·모서리 오판정·삭제·중복 기록을 확인한다.

## 시각과 수명 계약

Step에 같은 시계의 구간 시작/끝을 전달한다. Contact.time은 해당 시계의 시각이고 fraction은 구간 내 0~1이다. 탈출 시계와 전투 시계가 다르면 fraction을 탈출 시간 구간에 매핑한다. 동일 시점 후보의 게임상 우선순위는 콘텐츠가 함께 처리한다. 안정적인 정렬은 제공하지만 정렬 순서 자체를 피해 규칙으로 사용하지 않는다.

처음 등록되거나 공격 식별·크기가 바뀐 판정은 현재 시점부터 유효하다. 공격 시작/활성 직전 위치를 확보하려면 콘텐츠가 활성 시작 시점을 샘플링해야 한다. 곡선 검 궤적을 프레임 양 끝의 직선만으로 완벽하게 검사하지는 못한다. 필요한 공격은 같은 시간축의 중간 샘플을 공급해야 한다.

회전된 Box는 월드 AABB로 확장되며 OBB 판정이 아니다. 비균일 스케일/부모 shear의 Sphere는 보수적인 외접 구다. 삭제·비활성 판정은 후보에서 제외한다. 삭제 대상에 대한 Exit 통지는 만들지 않으므로 콘텐츠는 객체 수명 종료 때 구독/상태도 정리한다. Trigger를 한 프레임에 관통하면 Enter와 Exit를 반환한다. 정확한 연속 시각은 진입에 제공하며 Exit는 구간 끝 시각이다. position은 접촉 시 첫 객체 중심의 근사 위치다.

## 실행과 검증

F5 → WASD로 황색 상자를 오른쪽 적색 상자에 접근시키면 로그에 Trigger 진입 시각이 남는다. 이것은 판정 사용 예제이며 플레이어 공격/피해 구현은 아니다.

2026-10-06 `scripts/verify.ps1`의 Debug/Release 빌드·엔진 테스트·두 GPU smoke-test 통과. 10초 구간 중 3.75초에 진입하는 탈출 사례, 기한과 동일 시각의 비교, 빠른 구의 0.48초 접촉, 구/상자 모서리의 과도한 판정 제외, 삭제 후 후보 없음, Ray의 최근접 거리와 공격/대상 중복 기록을 검증했다.
