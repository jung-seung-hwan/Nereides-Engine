# 에셋 폴더 안내

모델·애니메이션·텍스처·음원은 별도 공유 드라이브에서 받아 배치한다. Git LFS는 사용하지 않는다. Git에는 이 안내와 폴더 유지를 위한 `.gitkeep`만 저장한다.

| 폴더 | 저장할 내용 |
| --- | --- |
| models/ | 게임에서 사용할 모델과 모델별 패키지 |
| animations/ | 별도로 제공된 애니메이션 파일 |
| textures/ | 독립적으로 공유하는 텍스처 |
| audio/bgm/ | 배경음악 |
| audio/sfx/ | 효과음 |
| presentation/ | 2D·2.5D 연출용 이미지 등 리소스 |

공유 드라이브도 이 경로 구조를 사용한다. 프로젝트 루트 기준 상대 경로로 참조하고, 에셋 버전과 필요한 파일 목록을 함께 공유한다. 현재 별도 애니메이션 파일의 자동 연결·리타게팅이나 오디오 재생 기능이 구현됐다는 의미는 아니다.

모델에 포함된 애니메이션은 모델 파일 안에 그대로 둔다. 모델 패키지 내부의 텍스처·모션·원본 파일은 서로 상대 경로로 연결될 수 있으므로 임의로 분리하지 않는다. 예를 들어 `models/character/textures`처럼 모델별 폴더 내부에 텍스처가 있어도 된다.

기존 `black_sword`, `deck`, `kraken_head`, `kraken_tentacle`, `kraken_tentacle2`는 제작 스크립트와 문서의 경로 호환을 위해 현재 위치를 유지한다. 루트의 `MMD/`도 기존 원본 보관 위치로 유지한다. 새 에셋은 위 표준 폴더를 사용하고, 기존 자료 이동은 제작 도구·씬 참조를 함께 변경할 때 진행한다.

씬 배치와 게임 설정은 `data/`에 저장해 Git으로 공유한다. 런타임 모델은 `assets/`, 기획 참고 이미지는 `docs/references/`로 구분한다. 현재 배포 스크립트는 외부 assets를 자동 포함하지 않는다.
